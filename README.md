# 日報集計VBA

複数のExcelファイルにある「日報」シートを集約し、  
集計用ブック `日報集計.xlsx` を作成するVBAです。

## 概要

このVBAは、指定したフォルダ内のExcelファイルを順番に開き、  
各ファイルの「日報」シートをコピーして整形し、  
最終的にDB形式のシートへまとめます。

## 主な処理

- フォルダ選択
- 指定フォルダ内のExcelファイル検索
- 各ブックの「日報」シート取得
- 不要列の削除
- 合計行・不要行の削除
- 配列を使ったデータ整形
- `DB用日報` シートへの出力
- `日報集計.xlsx` として保存

## 想定している前提

- 対象ファイルは同一フォルダ内にある
- 各ファイルに `日報` という名前のシートが存在する
- レイアウトがある程度統一されている
- 集計後の保存先は選択フォルダ内

## ファイル構成

- `src/Module1.bas`
  - メイン処理
  - フォルダ選択
  - 行削除処理
  - 配列処理
- `src/Module2.bas`
  - 最終行取得
  - 最終列取得

## 実行方法

1. ExcelでVBAエディタを開く
2. 標準モジュールにコードを貼り付ける
3. `BE` を実行する
4. 対象フォルダを選択する
5. 集計結果として `日報集計.xlsx` が作成される

## 注意点

- 元データのレイアウトが違うと正しく処理できない可能性があります
- シート名 `日報` が固定で使われています
- 削除処理が多いため、元ファイルの構成に依存します
- 必要に応じてバックアップを取ってから使用してください
